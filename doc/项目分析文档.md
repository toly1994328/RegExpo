# RegExpo 项目分析文档

## 1. 项目概述

RegExpo（正则通）是一个跨平台的正则表达式工具应用，基于 Flutter 框架开发，支持桌面端（Windows、Linux、macOS）和移动端（Android、iOS）以及鸿蒙系统（OHOS）。该应用提供了正则表达式测试、匹配、保存和管理功能，帮助用户更高效地使用正则表达式。

## 2. 技术栈

- **框架**：Flutter
- **状态管理**：flutter_bloc（Bloc 模式）
- **数据持久化**：sqflite（SQLite）
- **平台适配**：针对桌面端和移动端有不同的 UI 实现

## 3. 项目架构

项目采用了清晰的分层架构，主要包括以下几个层次：

### 3.1 表现层（UI）

- **views**: 包含所有的界面组件
  - **desk_ui**: 桌面端界面
  - **phone_ui**: 移动端界面
  - **adapter**: 平台适配相关组件

### 3.2 业务逻辑层（BLoC）

- **blocs**: 使用 BLoC 模式管理应用状态
  - **app_config**: 应用配置相关状态
  - **link_regex**: 关联正则表达式状态
  - **match**: 正则匹配状态
  - **record**: 记录管理状态

### 3.3 数据层

- **models**: 数据模型定义
  - **app_config**: 应用配置模型
  - **link_regex**: 关联正则表达式模型
  - **match**: 匹配相关模型
  - **record**: 记录模型

- **repositories**: 数据仓库
  - **impl**: 具体实现
    - **db**: 数据库相关实现
  - **parser**: 正则表达式解析器

### 3.4 公共组件

- **components**: 可复用的 UI 组件
- **utils**: 工具类

## 4. 核心功能模块

### 4.1 正则表达式匹配（Match）

核心功能是正则表达式的匹配和测试。通过 `RegexParser` 类实现正则表达式的解析和匹配，支持以下功能：

- 实时匹配显示
- 匹配结果高亮显示
- 分组匹配结果展示
- 匹配配置调整（多行、大小写敏感、Unicode、点号匹配所有）

相关文件：
- `lib/src/repositories/parser/regex_parser.dart`
- `lib/src/blocs/match/bloc.dart`
- `lib/src/models/match/match_info.dart`
- `lib/src/models/match/regexp_config.dart`

### 4.2 记录管理（Record）

允许用户保存和管理正则表达式及其匹配内容：

- 创建、编辑、删除记录
- 记录列表展示
- 记录详情查看
- 从文件导入内容

相关文件：
- `lib/src/models/record/record.dart`
- `lib/src/blocs/record/record_bloc.dart`
- `lib/src/repositories/impl/db_recode_repository.dart`

### 4.3 关联正则表达式（Link Regex）

为特定内容关联推荐的正则表达式：

- 添加、删除关联正则表达式
- 快速应用关联的正则表达式

相关文件：
- `lib/src/models/link_regex/link_regex.dart`
- `lib/src/blocs/link_regex/link_regex_bloc.dart`
- `lib/src/repositories/impl/db_link_regex_repository.dart`

### 4.4 应用配置（App Config）

管理应用的全局配置：

- 主题设置（亮色/暗色模式）
- 界面布局设置

相关文件：
- `lib/src/app/style/app_theme_data.dart`
- `lib/src/blocs/app_config/bloc.dart`
- `lib/src/models/app_config/app_config.dart`

## 5. 数据持久化

应用使用 SQLite 数据库进行数据持久化，主要包括以下表：

### 5.1 记录表（recoder）

```sql
CREATE TABLE `recoder` (
  `id` INTEGER PRIMARY KEY AUTOINCREMENT,
  `title` VARCHAR(256),
  `content` TEXT,
  `timestamp` INTEGER
)
```

### 5.2 关联正则表达式表（link_regex）

```sql
CREATE TABLE `link_regex` (
  `id` INTEGER PRIMARY KEY AUTOINCREMENT,
  `regex` TEXT,
  `record_id` INTEGER,
  `timestamp` INTEGER,
  UNIQUE(record_id,regex)
)
```

数据库版本管理通过 `DbUpdater` 和 `DbMigration` 类实现，当前数据库版本为 3。

## 6. 用户界面

应用针对不同平台提供了不同的用户界面：

### 6.1 桌面端界面（desk_ui）

桌面端采用分栏式布局：
- 左侧导航栏：示例、匹配、收藏
- 中间内容区：文本内容和匹配结果展示
- 右侧导航栏：关联正则、笔记、帮助

### 6.2 移动端界面（phone_ui）

移动端采用标签页式布局：
- 底部导航栏：主页、匹配、记录、用户
- 顶部操作栏：根据当前页面提供相应功能

## 7. 平台适配

应用通过以下方式实现跨平台适配：

- `PlatformAdapterBar`: 平台适配组件
- `WindowsAdapter`: Windows 平台特定适配
- `SystemTrayWrapper`: 系统托盘适配

## 8. 项目特点

1. **跨平台支持**：同时支持桌面端和移动端，提供针对不同平台优化的 UI
2. **实时匹配**：正则表达式输入后实时显示匹配结果和高亮
3. **分组匹配**：支持正则表达式分组匹配，并以不同颜色显示
4. **数据持久化**：使用 SQLite 数据库保存用户记录和关联正则表达式
5. **主题切换**：支持亮色和暗色主题
6. **文件导入**：支持从文件导入内容进行匹配
